Mercury объединяет нативные инструменты mx, среду DOM Hyperscript, состояние Hypergraph и компоненты Mercury UI. Браузерные приложения можно связать с Phoenix и LiveView через Live Mercury. Нативный цикл разработки приложения не требует React, Node.js и npm CLI. Этот сайт объясняет каждый модуль и его текущие ограничения.

## С чего начать

1. **Создайте приложение с mx.** Нативный набор инструментов: модули, цикл разработки, сборка и поставка. [Перейти к курсу mx](/ru/mx).
2. **Напишите компоненты.** Mercury Hyperscript, виртуальный DOM и хуки. [Перейти к курсу Hyperscript](/ru/hyperscript).
3. **Используйте Mercury UI.** Компоненты и токены дизайн-системы. [Перейти к курсу UI](/ru/ui).
4. **Опишите состояние.** Hypergraph — ядро управления состоянием. [Перейти к курсу Hypergraph](/ru/hypergraph).
5. **Публикуйте страницы.** Документы страниц и каталог блоков. [Перейти к курсу Content](/ru/content).
6. **Встраивайте острова в Phoenix и LiveView.** Mercury на BEAM. [Перейти к курсу Live Mercury](/ru/live-mercury).
7. **Найдите API в справочнике.** Справочник, сформированный из исходников каждого пакета, появится на одном из следующих этапов.
8. **Передайте документацию агенту.** Добавьте `/llms.txt` к адресу любой страницы.

## Модули

| Модуль | Назначение | Импорт |
|---|---|---|
| mx | нативный набор инструментов: сборка, цикл разработки, тесты | команда `mx` |
| Hyperscript | виртуальный DOM, среда выполнения JSX и хуки | `@fiberfx/hyperscript` |
| Mercury UI | компоненты и токены дизайн-системы | `@fiberfx/ui` |
| Hypergraph | ядро управления состоянием | `@fiberfx/hypergraph` |
| Content | документы страниц и каталог блоков | `@fiberfx/content` |
| Live Mercury | острова Mercury в Phoenix и LiveView | Mix-пакет `live_mercury` |

## Статус

Главная страница доступна на английском и русском. В курсах готовые возможности отделены от запланированных. Перед выбором модуля проверьте [его готовность](/ru/start/stability), а текущий способ получить инструменты описан в [установке mx](/ru/start/install-mx). Публикация пакета в реестре сама по себе не подтверждает, что нативная установка работает: следуйте проверенным шагам в [руководстве по первому приложению](/ru/mx/first-app).

## Для агентов

По адресу каждой страницы с добавленным `/llms.txt` доступна её краткая текстовая версия, написанная вручную: назначение страницы, её контракт, минимальный пример и имена, которые нельзя выдавать в ответах. Карта сайта доступна по адресу `/llms.txt`.
