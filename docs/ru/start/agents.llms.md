# Создайте страницу с агентом — Mercury LMS

> [Навык Mercury](/agent/SKILL.md) сохраняет существующее приложение и выбирает работающий mx, браузерный HTML или доступный способ установки нативного инструмента.

## Выбор и проверка

- Без CLI: [браузерная страница](/ru/start/browser/llms.txt), обычный JavaScript h/render, закреплённые импорты UNPKG и link на стили UI. Требуется сеть; TSX в браузере не исполняется.
- Для нативного TSX: [готовность установки](/ru/start/install-mx/llms.txt), npm для получения mx либо архив с проверкой сумм. После этого [нативная страница](/ru/mx/first-app/llms.txt), mx install/verify/dev/build. Сохраните mx.mod и mx.sum.
- Проверьте оформление и заказанные взаимодействия в браузере. Счётчик 0 → 1 → 2 относится только к примеру. Для нативного пути проверьте также страницу из dist/ через HTTP. Укажите проверки, которые не удалось выполнить.

Используйте Hyperscript и Mercury UI. Стили: import @fiberfx/ui/styles.css в нативном приложении, link на закреплённую таблицу стилей в браузерном HTML. JavaScript исполняется в браузере; Phoenix/LiveView необязательны. /SKILL.md — совместимый адрес того же навыка. Публикация требует разрешения пользователя.
