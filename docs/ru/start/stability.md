Публикация пакета и проверка платформы — разные утверждения. Кандидат нативной установки требует Linux x86_64 с glibc 2.39 или новее (требование ELF измерено; проверка у потребителя ещё не выполнена); см. [Установка mx](/ru/start/install-mx) и [метаданные выпуска](/downloads.json). macOS и Windows этим путём не проверены.

## Три уровня готовности

- **Shipped — опубликовано.** Пакет можно установить из реестра в указанной версии.
- **Preview — предварительная версия.** Реализация с указанными ограничениями. Сборка может быть доступна для загрузки; это не подтверждает стабильность API или поддержку всех платформ. Её можно изучать в курсе.
- **Planned — запланировано.** Возможность описана в плане программы, но не реализована. Страница с этой пометкой не содержит примера, который можно запустить.

Пятнадцать публичных модулей `@fiberfx` имеют статус Shipped: версия 4.0.0 опубликована в npm 2026-11-05, и для каждого модуля `latest` указывает на 4.0.0. Накануне npm ещё отвечал для них «не найдено». Предыдущая основная версия, 3.x, остаётся опубликованной в npm под прежним пространством имён `@mercury-fx/*` (`@mercury-fx/ui` там имеет версию 3.0.0). `mx`, `live_mercury` и внутренние модули по-прежнему имеют статус Preview.

## Как меняются версии

Модули `@fiberfx` выпускаются вместе под одной версией. 4.0.0 — новая основная версия, потому что все имена импортов меняются относительно пространства имён 3.x. Компилятор и языковой сервер сохраняют собственные версии, поскольку ни один не публикуется как пакет. У `mx` и `live_mercury` также свои версии.

## Что запланировано

- **Hypergraph:** ещё два пути экспорта — `/hyperscript` (интеграция с Hyperscript) и `/hmr` (горячая замена).
- **mx:** `mx dev` уже поддерживает горячую перезагрузку с механизмом отслеживания изменений и клиентом ([MX2](/ru/mx/dev)); доставка через него замены Hypergraph с сохранением состояния ожидает `/hmr`, указанный выше. Модули уже собираются и тестируются с помощью mx; pnpm остаётся только для приложений и инструментов в `node/`.
- **Для агентов:** `<page>.md`, `/agents` и поиск. (`/llms-full.txt` уже доступен.) См. [Для агентов](/ru/start/agents).
