# Стабильность: опубликовано, предварительная версия, запланировано — Mercury LMS

> Уровни готовности: Shipped — опубликовано в реестре; Preview — предварительная реализация с ограничениями; доступная сборка не означает стабильность API или поддержку всех платформ; Planned — описано в плане, не реализовано, примера для запуска нет. Пятнадцать публичных модулей `@fiberfx` версии 4.0.0 имеют статус Shipped: доступны в npm с 2026-11-05, `latest` — 4.0.0. Версия 3.x остаётся опубликованной в npm под именами `@mercury-fx/*`.

## Когда читать

Если вы собираетесь предложить пользователю установить пакет Mercury, закрепить версию или опереться на API и хотите выяснить, существует ли он, в какой версии и опубликован ли релиз.

## Модули

- Shipped, 4.0.0 в npm: `@fiberfx/hyperscript`, `render-to-string`, `core`, `ui`, `hypergraph`, `schema`, `content`, `cms`, `analytics`, `phoenix`, `phoenix_live_view`, `live-mercury`, `testing`, `devtools` (только для разработки), `vite-plugin-mhs`.
- Preview, внутренние, не публикуемые как пакеты: `@fiberfx/hypercompiler` 3.0.0, `@fiberfx/hyperscript-lsap` 0.1.0.
- Preview: `mx` 0.1.0 (кандидаты npm и архива требуют Linux x64/glibc 2.39+; публикация и проверка у потребителя ещё не выполнены: /ru/start/install-mx; метаданные: /downloads.json).
- Preview: `live_mercury` 2.8.0 (Mix; не опубликован в Hex).
- Этот сайт: `mercury_lms` 0.1.0. Главная страница, формируемая Phoenix, по адресам `/` и `/ru`; курсы доступны по своим путям. Публичный хост: `mercury.jonnify.com`; предварительный: `mercury-next.jonnify.com`.

Курсы уже доступны: Start, mx, Hyperscript, Mercury UI, Hypergraph, Content и Live Mercury.

## Запланировано

- `@fiberfx/hypergraph/hyperscript` и `@fiberfx/hypergraph/hmr`: не экспортируются.
- Доставка замены Hypergraph с сохранением состояния через `mx dev` ожидает `/hmr`. (Уже сделано: `mx dev` выполняет горячую перезагрузку модулей, /ru/mx/dev; модули собираются и тестируются с помощью mx; pnpm остаётся только для приложений и инструментов в `node/`.)
- `<page>.md`, `/agents`, поиск. (`/llms-full.txt` уже доступен.)

## Правила

- Пакеты `@fiberfx` версии 4.0.0 доступны в npm, но нативное приложение устанавливает зависимости через `mx install`. Отдельная начальная установка через npm получает исполняемый файл mx после публикации; см. [готовность установки](/ru/start/install-mx/llms.txt).
- Никогда не ссылайтесь на `mx push`: в этой ревизии у mx нет такой команды.
- Никогда не представляйте перечисленные выше имена со статусом Planned как доступные для импорта.
- Указывайте версию только по этой странице или по `package.json` модуля.
