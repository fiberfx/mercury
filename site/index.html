The Mercury interface system

Build interfaces natively.

Build interfaces with Hyperscript, model state with Hypergraph, and compose them with Mercury UI. One native toolchain, mx, connects the development workflow. For BEAM integration, use Phoenix and LiveView with Live Mercury.

01values and principles

A design system serving products. Built for the work.

Reusable components, explicit state, and a native development loop. Each part has a clear job.

01 · efficiency

Build on shared foundations.

Use the same components and tokens across a product. Spend time on its behavior and content, with one place to improve the foundations.

Explore Mercury UI →

02 · agility

Change without losing the model.

Hypergraph separates events, state and effects. Hyperscript renders the interface with the browser’s own DOM semantics.

Learn Hypergraph →

03 · quality

Make the contract visible.

Read each component’s behavior, limits and examples. The documentation distinguishes what is available from what is still being built.

Check readiness →

02why mercury

One system. Distinct products.

Shared building blocks give each product room to express itself through content, composition and tokens.

A common interface language

Buttons, forms, navigation and feedback use the same component contracts throughout the product.

Less repeated work

Developers compose existing controls. A correction to a shared component benefits every place that uses it.

State you can follow

Hypergraph makes events, derived values and effects explicit, including isolated state for server requests.

A native development loop

mx compiles, serves and bundles Mercury applications. Hyperscript uses class, for and native DOM events.

HTML first on the BEAM

Phoenix renders readable pages on the server. Live Mercury adds an island where interaction needs one.

05getting started

Your first page. Try it here.

Open a working Mercury page in your browser, build locally with mx, or add Mercury to Phoenix. Choose your route in the getting-started guide.

Try in browser

Open the complete HTML · Browser guide

Plain JavaScript

import { h, render } from "@fiberfx/hyperscript";
import { useState } from "@fiberfx/hyperscript/hooks";
import { Card, Button } from "@fiberfx/ui";

function Counter() {
  const [count, setCount] = useState(0);
  return h(Card, { title: "My first Mercury page", variant: "raised" },
    h("p", { id: "count", "aria-live": "polite" }, `Count: ${count}`),
    h(Button, { onClick: () => setCount(count + 1) }, "Increment")
  );
}
render(h(Counter, null), document.getElementById("app"));

The complete HTML maps these imports to Mercury 4.0.0 modules and links the UI stylesheet. Keep the import map and CSS together; this browser example needs network access to unpkg.com.
