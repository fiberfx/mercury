Создайте страницу с агентом

Навык задаёт путь к первой странице, а текстовые версии уроков помогают уточнить API.

Агент выбирает способ работы по задаче и доступным инструментам. Сохраните существующее приложение или работающий mx; без CLI можно создать страницу в браузере. Для нативной разработки проверьте готовность установки. Навык Mercury описывает все три пути; Phoenix и LiveView необязательны.

Дайте агенту конкретную задачу

Прочитай https://mercury.jonnify.com/agent/SKILL.md и создай
страницу Mercury по моей задаче. Сохрани существующее приложение
и работающие инструменты. Если mx недоступен, выбери браузерный
HTML или доступную нативную установку по требованиям задачи.
Проверь оформление и нужные действия в браузере. Для нативного
пути собери dist/ и проверь сборку. Сообщи о непроверенных шагах.

Опишите нужное содержимое и поведение: например, карточки товаров с фильтром или форму с проверкой ввода. Счётчик Card + Button — учебный пример, а не обязательный результат для любой задачи. Браузерный и архивный пути обходятся без Node/npm; планируемый npm-путь устанавливает обёртку, которой Node нужен и для последующих вызовов mx.

Навык для страницы Mercury

/agent/SKILL.md задаёт способ установки, импорты, подключение стилей и проверки результата. Подключите файл через механизм навыков вашего агента или попросите прочитать его по URL. Сайт не устанавливает плагин агента и не предоставляет разрешение на публикацию.

Навык предназначен для создания или редактирования страницы Mercury в выбранной пользователем рабочей области. Он не требует менять посторонние проекты или заменять их фреймворк.

Чтение документации

Добавьте /llms.txt к адресу урока, чтобы получить написанную вручную текстовую версию:

  • Карта сайта
  • Установка
  • Первая страница
  • Mercury UI
  • Все английские текстовые версии одним файлом

Русские уроки находятся под /ru/; английские — без этого префикса. Текстовая версия кратко излагает тот же контракт, что и страница, а не отдельный API. Используйте документированные адреса; не угадывайте пути .md и поиска.

Отчёт о проверках

Проверьте оформление и действия, требуемые пользователю, включая подходящий ошибочный ввод или граничное условие. Разделяйте установку, запуск сервера, наблюдавшееся взаимодействие и сборку. Браузерному пути сборка не нужна. Для стартового приложения проверьте оформление Card и Button, изменение счётчика с 0 на 1 и 2, сохранённую правку заголовка и страницу из dist/ через HTTP-сервер. Если в среде нет браузера или доступа к loopback, укажите ограничение: одна сборка не подтверждает взаимодействие.

Сохраняйте импорты @fiberfx. Нативное приложение импортирует @fiberfx/ui/styles.css; mx компилирует TSX и предоставляет среду JSX. Браузерный HTML подключает закреплённую таблицу стилей через link и использует вызовы h на обычном JavaScript, без TSX и компилятора. На обоих путях JavaScript исполняется в браузере. Перед обещанием другой платформы или интеграции проверьте Стабильность.
