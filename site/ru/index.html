Система интерфейсов Mercury

Создавайте интерфейсы с Mercury.

Стройте интерфейсы на Hyperscript, описывайте состояние с Hypergraph и собирайте страницы из Mercury UI. Нативный набор инструментов mx объединяет цикл разработки. Для интеграции с BEAM используйте Phoenix и LiveView вместе с Live Mercury.

01ценности и принципы

Дизайн-система для продуктов. Для вашей работы.

Переиспользуемые компоненты, явное состояние и нативный цикл разработки. У каждой части своя задача.

01 · эффективность

Опирайтесь на общие основы.

Используйте одни компоненты и токены во всём продукте. Уделяйте время его поведению и содержимому, улучшая общие основы в одном месте.

Изучить Mercury UI →

02 · гибкость

Меняйте интерфейс, сохраняя модель.

Hypergraph разделяет события, состояние и эффекты. Hyperscript отображает интерфейс с нативной семантикой DOM браузера.

Изучить Hypergraph →

03 · качество

Понимайте контракт.

Читайте о поведении, ограничениях и примерах каждого компонента. Документация различает готовые возможности и то, что ещё разрабатывается.

Проверить готовность →

02почему mercury

Общая система. Разные продукты.

Общие элементы позволяют каждому продукту выразить себя через содержимое, композицию и токены.

Общий язык интерфейса

Кнопки, формы, навигация и обратная связь используют одинаковые контракты компонентов во всём продукте.

Меньше повторной работы

Разработчики собирают интерфейс из готовых элементов. Исправление общего компонента действует везде, где он используется.

Понятное состояние

Hypergraph явно описывает события, производные значения и эффекты, включая изолированное состояние серверных запросов.

Нативный цикл разработки

mx компилирует приложения Mercury, запускает сервер разработки и собирает бандлы. Hyperscript использует class, for и нативные события DOM.

Сначала HTML, на BEAM

Phoenix формирует HTML страниц на сервере. Live Mercury добавляет интерактивные острова там, где они нужны.

05начало работы

Ваша первая страница. Попробуйте здесь.

Откройте рабочую страницу Mercury в браузере, собирайте локально с mx или добавьте Mercury в Phoenix. Выберите путь в руководстве начала работы.

Попробовать в браузере

Открыть полный HTML · Руководство для браузера

Обычный JavaScript

import { h, render } from "@fiberfx/hyperscript";
import { useState } from "@fiberfx/hyperscript/hooks";
import { Card, Button } from "@fiberfx/ui";

function Counter() {
  const [count, setCount] = useState(0);
  return h(Card, { title: "My first Mercury page", variant: "raised" },
    h("p", { id: "count", "aria-live": "polite" }, `Count: ${count}`),
    h(Button, { onClick: () => setCount(count + 1) }, "Increment")
  );
}
render(h(Counter, null), document.getElementById("app"));

Полный HTML связывает эти импорты с модулями Mercury 4.0.0 и подключает стили UI. Сохраняйте карту импортов вместе с CSS; браузерному примеру нужен доступ к unpkg.com.

Собирать локально с mx

Начните с архива первой страницы, где уже закреплены версии модулей и контрольные суммы. Руководство проведёт через установку, запуск и сборку.

Архив нативного приложения пока отсутствует в текущем манифесте выпуска.
