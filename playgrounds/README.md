# Public examples

`site/playgrounds/counter/` is the native-built counter verified on Linux. `site/playgrounds/task-list/` contains real published Mercury modules and styles in one HTML file. These examples contain no private repository map. The six reusable playground templates are in `skills/mercury-playground/templates/`.

The code-map and Design Explorer artifacts are excluded because their owner identified repository-internal content requiring a separate public allowlist.
